**Short description:** Pick the right mobile car wash package and wash frequency for a car in the UAE climate. Zero dependencies, CLI and library.

**Long description:** see `README.md`. The package turns a car profile (vehicle type, parking, driving, cabin load, time since wax, deep interior clean and engine-bay clean, visible problems) into a recommended package, a wash interval and a dated visit plan with an AED cost range.

**Features:** four packages with published AED ranges; trigger-based recommendation with plain-language reasons; UAE-aware wash interval; dated plan with cost totals; JSON output; no dependencies.

**Publish:** `cd packages/npm && npm test && npm publish` (not run: publishing needs the owner's npm login).
